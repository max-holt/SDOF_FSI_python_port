# Rename table — for the owner's approval (charter ruling 10)

The rename table of the renames session is `docs/nomenclature.md` (session R.3). It is a
proposal: nothing is renamed until the owner has edited and approved it. Its "when" column
says which renames are made in the renames session (R), which with the parameter objects
(K, ruling 21) and which in the public API session (P); its last section holds the
questions Q-N1 to Q-N8.
